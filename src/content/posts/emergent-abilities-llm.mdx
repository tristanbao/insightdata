# 大模型的涌现能力：表象之下

2022 年，Google Research 发表了一篇被广泛引用的论文，题为《Emergent Abilities of Large Language Models》。论文指出，当语言模型的规模超过某个临界点时，会突然涌现出小模型完全不具备的能力——比如数学推理、多步计算、代码生成。

这一发现令人兴奋，也为"规模即一切"（scaling is all you need）的叙事提供了有力支撑。但两年后，另一批研究者发表了反驳论文，认为涌现能力很大程度上是一个**度量 artifact**，而非真实的相变。

## 什么是"涌现"？

在物理学中，涌现是指复杂系统表现出的、无法从组成部分直接预测的性质。比如水的"湿润性"无法从单个 H₂O 分子的性质推导出来。

在大模型的语境中，"涌现能力"指的是：当模型参数量从 N 增加到 N×10 时，在某项基准测试上的表现从随机水平突然跃升到远超随机水平。

这种非线性跳跃看起来确实像是相变。

## 反驳：评估指标的伪装

Schaeffer、Miranda 和 Kaddy 在 2023 年发表的论文提出了一个尖锐的批评：**如果你改变评估方式，许多"涌现"能力就消失了。**

关键洞察在于：大多数基准测试使用的是**粗粒度的离散指标**。以 BIG-Bench 中的任务为例，如果按准确率评分，模型确实会在某个规模点出现从 0 到 30% 的跳跃。但如果用平滑的 Brier Score 评估，同一能力的增长曲线几乎是线性的。

换句话说：瀑布变成了缓坡——只是因为你选择了特定的测量刻度。

```python
# 涌现 vs. 平滑：两种评分方式的结果差异

# 离散评分（准确率 - 常见做法）
scores = [0.01, 0.02, 0.03, 0.05, 0.08, 0.12, 0.35, 0.68, 0.82]
#                        ^~~~~ 看起来像涌现

# 连续评分（Brier Score / Perplexity - 更敏感的指标）
scores_smooth = [0.99, 0.97, 0.94, 0.91, 0.87, 0.82, 0.74, 0.61, 0.45]
#               ^~~~~ 线性下降，没有明显的相变
```

## 这场争论为何重要

这场争论的实质是：**我们用什么指标定义"智能"？**

如果用二元划分的准确率打分，模型能力的增长确实呈现非线性；如果用概率分布的平滑度量，增长则是渐进的。哪种更接近"真实"？

这个问题没有简单的答案，但它迫使我们反思：大模型能力的每一次"突破"，有多少是真实的技术进步，有多少是评估框架的产物？

## 对从业者的启示

对于 AI 应用开发者而言，这项研究提供了几个重要启示。

**第一，不要被基准测试数字绑架。** GPT-4 在某个榜单上超过人类，不意味着它在所有场景下都可用。特定任务的能力边界需要通过实际测试来验证。

**第二，关注能力曲线的形态，而非临界点。** 即使"涌现"是度量伪影，模型能力的提升趋势仍然是真实的——重要的是这条曲线的斜率和终点。

**第三，对Scaling Laws保持审慎乐观。** 规模法则（Scaling Laws）在经验上高度稳健，但它的预测力是外推的。没有人能保证下一代的模型能力增长曲线与过去一致。

## 尚未解决的开放问题

最深层的问题也许是：如果我们承认"涌现"是评估的产物，那么什么是衡量模型能力的**本真（intrinsic）**方式？

信息论提供了部分答案——我们可以测量模型对数据分布的拟合程度（perplexity），但这不能直接回答"模型是否理解了自己在做什么"。

这最终指向了可解释性 AI 的核心问题：当我们无法定义一个现象时，我们也无法测量它。
