# Markdown Syntax Guide

欢迎使用 InsightData 的文章编辑器。本指南覆盖了撰写文章所需的全部 Markdown 语法。

## 标题

使用 `#` 符号创建标题。支持一级到六级标题：

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 文字格式

你可以使用 **粗体**、*斜体*、~~删除线~~ 等格式。

```markdown
**粗体文本**
*斜体文本*
~~删除线~~
```

## 列表

### 无序列表

```markdown
- 第一项
- 第二项
  - 嵌套项
  - 嵌套项
- 第三项
```

### 有序列表

```markdown
1. 第一步
2. 第二步
3. 第三步
```

## 代码块

行内代码使用反引号：`const x = 1`。

多行代码块使用三个反引号，可指定语言：

```python
def hello_world():
    print("Hello, InsightData!")
```

## 引用

> 这是一段引用文本。
> 可以包含多行。
>
> 引用内也可以嵌套其他格式。

```markdown
> 这是引用文本
```
